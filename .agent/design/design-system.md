# Shopnix Design System

## 1. Design Philosophy
Shopnix embodies the clarity, density, and precision of modern world-class developer and enterprise tools (Linear, Stripe, Raycast, Vercel). 
- **Information Density:** High data density without visual clutter. Default to compact margins and clean dividers.
- **Predictability:** Consistent placement of actions, search bars, status indicators, and keyboard shortcuts.
- **Visual Restraint:** Neutral surfaces punctuated by a rich, modern Deep Indigo accent and deliberate semantic colors.

---

## 2. Core Token Summary

### Color Spectrum
- **Primary:** Deep Indigo (`oklch(0.45 0.15 280)`)
- **Background:** Crisp White / Deep Charcoal in dark mode
- **Surfaces & Cards:** Subtle elevated neutrals
- **Borders:** Ultra-subtle, high-contrast borders
- **Status Indicators:** Deliberate OKLCH green (delivered/success), warm amber (pending/warning), soft crimson (cancelled/returned/error).

### Spatial & Typography Metrics
- **Base Grid:** 8px rhythm (with 4px half-steps for micro-spacing).
- **Typography:** Geist Sans for general UI; Geist Mono for numeric figures, currencies, order numbers, and SKUs.
- **Corner Radii:** Modern 8px base radius (`rounded-lg`) with 6px inner radius (`rounded-md`).
- **Elevation:** Subtle layered shadows (`shadow-sm`, `shadow-md`) rather than heavy blurred drops.
